# Mondo – Übersetzer

Eine einfache, mobile Übersetzer-Web-App für Text- und Spracheingabe.

## Auf dem iPhone verwenden

1. Repository unter **Settings → Pages** veröffentlichen: **Deploy from a branch**, Branch `main`, Ordner `/ (root)` wählen und speichern.
2. Nach der Veröffentlichung die angezeigte Pages-Adresse in **Safari** auf dem iPhone öffnen.
3. In Safari auf **Teilen** tippen, **Zum Home-Bildschirm** auswählen und mit **Hinzufügen** bestätigen.
4. Mondo erscheint als Symbol auf dem Home-Bildschirm und lässt sich wie eine App öffnen.

Falls du die Pages-Einstellung nicht selbst ändern möchtest, kann eine Person mit Zugriff auf das Repository diese aktivieren. Die Übersetzungsfunktion verwendet den kostenlosen MyMemory-Webdienst; Verfügbarkeit und Nutzungslimits können sich ändern. Mikrofonzugriff und Spracheingabe hängen von iOS/Safari und den Geräteeinstellungen ab. Internetverbindung erforderlich.
